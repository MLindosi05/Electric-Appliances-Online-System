# Electric Appliances Online System

A Java-based system for managing online appliance and customer orders.

## Features
- Browse appliance catalog
- Place and manage orders
- Track inventory
- Object-oriented design for scalability

## Technologies Used
- Java
- SQL (if database integrated)
- OOP principles

## How to Run
1. Open the project in your IDE(i.e Visual Studio)
2. Compile and run the main Java file:

javac Main.java
java Main
